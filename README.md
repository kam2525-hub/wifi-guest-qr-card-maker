# Wi-Fiパスワード入力代行！来客用ワンタッチ接続カード作成メーカー

複雑なWi-Fiのパスワードをスマホで読み取るだけのQRコード付き接続カードを即座に作成・印刷できるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/wifi-guest-qr-card-maker/）。
2. 画面の指示に従って操作します。
